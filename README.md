\# WishList Web Application



A clean, responsive web application for creating and managing personal wishlists with priority tagging and real-time budget tracking.



\## ✨ Features

\- \*\*Add Items:\*\* Quickly add new wishes with a title, price, and priority level.

\- \*\*Wishlist Cards:\*\* Structured card layout displaying item details and priority tags.

\- \*\*Budget Tracking:\*\* Automatic real-time calculation of the total cost of all desired items.

\- \*\*Responsive Design:\*\* Adapts smoothly to desktop and mobile screens.



\## 🛠️ Tech Stack

\- \*\*HTML5\*\* — semantic page structure

\- \*\*CSS3\*\* — modular styling and responsive layout

\- \*\*Vanilla JavaScript\*\* — DOM manipulation, item management, and cost calculation



\## 🚀 Getting Started

1\. Clone the repository: `git clone \[https://github.com/matematik1/WishList-web.git](https://github.com/matematik1/WishList-web.git)`

2\. Open `index.html` in any modern web browser.
